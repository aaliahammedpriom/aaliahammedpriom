## 🧑‍💻 About Me <a name="about-me"></a>

Full-Stack Developer at **Softvence Alpha** (a concern of Betopia Group), based in Dhaka, Bangladesh. My core stack is MERN, with a strong backend focus on **Node.js, Express, and TypeScript** — building on production experience from **Innovative IT Solutions Limited**.

- 🛠️ Backend work centers on **Node.js / TypeScript / Express**, with **Prisma** for data access and **Redis** for caching
- ✅ Using **Zod** for schema validation and auto-generating **Swagger / OpenAPI 3.0** docs directly from route definitions
- 🔐 Actively transitioning toward **DevSecOps and Cybersecurity** on top of my full-stack foundation — currently deep in a **Docker Certified Associate (DCA)** and production Docker mastery track
- 📄 Recurring side-output: production-quality **bilingual (English + Bangla)** technical documentation and study guides
- 🌟 **Fun Fact:** I love debugging code as much as solving puzzles in my free time!
